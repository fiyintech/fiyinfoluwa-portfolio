Biography

I'm Fiyinfoluwa Akinyemi, an AI developer and Computer Science student who builds practical software at the intersection of machine intelligence and security. My work spans conversational AI assistants, automation tooling and web platforms that replace manual, error-prone processes with reliable systems.

I write mostly Python, work daily on Linux, version everything with Git, and care deeply about clean architecture, readable code and secure defaults. I learn by shipping — every project I take on is designed to solve a real problem for real people.
